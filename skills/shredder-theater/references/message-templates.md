# Message Templates — 收尾文案库

收尾文案是这个页面的全部意义。规则：**一句话、具体、带称呼或动作**，让人看完想截图。

## 怎么用

1. 先判断场景：日常清理 / 职场体面 / 情绪宣泄 / 自我关怀 / 仪式感告别 / 玩笑
2. 从对应分类挑一条，**把称呼换成用户指定的**（用户说"我妈"就别写"主人"）
3. 用户已经给了文案就原样用，只调标点
4. 文案超过 14 个字就缩短——长句在竖屏里会挤，冲击力反而散

## 日常清理

- 主人，已处理完毕
- 清空完毕，世界清爽了
- 处理完了，不留痕迹
- 都碎好了，安心
- 收拾干净，今天清爽

## 职场体面

- 已处理，请放心归档
- 本次清理已生效
- 相关内容已销毁，流程留痕
- 处理完毕，无后续
- 已碎，报告同步完成

## 情绪宣泄

- 已碎，不接受复活
- 全部粉碎，不再想起
- 碎得彻底，一干二净
- 没了，彻底没了
- 灰都不剩，干干净净

## 自我关怀

- 累了就丢这儿，不用心疼
- 扔掉的是旧版本，不是你
- 这些不重要，你才重要
- 处理完了，轻装上阵
- 先碎掉旧的，再往前走

## 仪式感告别

- 承蒙厚爱，到此为止
- 这一程，多谢同行
- 故事很好，现在收尾
- 敬我们走过的这一段
- 落幕了，后会有期

## 玩笑

- 文件已阵亡，谢绝复活
- 碎纸机已就位，请投入
- 您的文件已被永久粉碎
- 吃掉，不吐骨头
- 别问，问就是没了

## 备选句式（自己拼）

- `<称呼>，<状态>`：主人，已处理完毕 / 妈妈，清理好了
- `<状态>，<态度>`：处理完了，不留后路
- `<承诺>`：碎掉的东西，我不回头
- `<时间感>`：这些东西的保质期，到今天为止

## 禁忌

- 写「删除成功」「操作已完成」「已删除 3 个文件」——这是系统提示语，不是情绪落点
- 写超过两句话——碎纸机页面的收尾要像收刀，一句就够
- 在文案里堆 emoji
- 把用户没说的人称改掉（"主人"通常是示例，用户给什么称呼就用什么）
